🎵 HOW TO ADD CUSTOM MUSIC (OPTIONAL):
===================================================================

The website already comes with a built-in dreamy Lo-Fi romantic piano 
melody generated in real-time using the Web Audio API, so it plays 
instantly anywhere without needing to download anything!

However, if you have a favorite romantic song that Tuli loves (e.g. Kesariya, 
Raataan Lambiyan, Perfect by Ed Sheeran, or any romantic MP3):

1. Copy your MP3 song into this "music" folder.
2. Rename it to: song.mp3
3. The website will automatically detect and play your custom song!
